# ClaudeCoding
pruebas de codigos

## Apps

- [`app/`](app) — gestor de tareas académico (proyectos, tareas, notas, reuniones).
- [`estructural/`](estructural) — GeoEstructura: app de docencia en geología
  estructural. Digitaliza curvas de nivel, contactos y fallas sobre un mapa
  importado; calcula contornos estructurales, rumbo y manteo, perfiles
  estructurales, modelo 3D y columnas de pozos. Ver
  [`estructural/README.md`](estructural/README.md).
- [`geophoto/`](geophoto) — GeoPhoto Studio: fotos geolocalizadas sobre un mapa,
  exportación a Google Earth (KML/KMZ) y editor vectorial de anotaciones con rótulos
  de rumbo. Ver [`geophoto/README.md`](geophoto/README.md).
